# نموذج بيانات المشاريع

المصدر المنظم: `data/projects.json`.

كل مشروع يستخدم معرّفاً ثابتاً لا يعتمد على ترتيب البطاقة. الحقول `image`, `detailPage`, و`workflowFile` مسارات نسبية إلى جذر الموقع. استخدم `null` عندما لا يتوفر ملف، ولا تستخدم روابط وهمية. الحالات المقبولة: `draft`, `published`, `archived`.

عند إضافة مشروع:
1. أضف سجلاً جديداً بمعرّف غير مستخدم.
2. تحقق من وجود الصورة وصفحة التفاصيل فعلياً.
3. لا تضع أسراراً أو بيانات دخول داخل بيانات المشروع.
4. شغّل `npm run check:projects` ثم `npm run check`.
5. لا تغيّر حالة المشروع إلى `published` إلا بعد مراجعة محتواه وروابطه.

الكتالوج في هذه المرحلة تأسيسي ولا يزال العرض الحالي في `projects.html` ثابتاً؛ الانتقال إلى العرض الديناميكي خطوة منفصلة لتجنب كسر تجربة المستخدم.
