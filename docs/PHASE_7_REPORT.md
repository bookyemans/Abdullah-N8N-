# تقرير المرحلة السابعة — تنظيم القوالب والمكونات المشتركة

## الهدف
تقليل تكرار صيانة رأس الصفحة (Header) وتذييلها (Footer) مع الحفاظ على HTML ثابت وقت النشر، حتى لا يعتمد الموقع على تحميل أجزاء الواجهة عبر JavaScript ولا يتأثر عمله على Cloudflare Pages.

## ما تم تنفيذه
- استخراج رأسي الصفحات وتذييلاتها من الصفحات الست الأساسية إلى ملفات مصدر مستقلة داخل `shared/components/`.
- إنشاء 12 مكوناً مصدرّياً: Header وFooter لكل من `index.html` و`about.html` و`services.html` و`projects.html` و`blog.html` و`contact.html`.
- إضافة علامات واضحة داخل صفحات HTML تربط كل موضع بمصدره المعتمد.
- إنشاء `scripts/build-shared-components.mjs` لإعادة توليد HTML الثابت من ملفات المكونات.
- إنشاء `scripts/check-shared-components.mjs` للتحقق من تطابق المكونات المضمّنة مع مصادرها.
- إضافة أوامر `npm run build:components` و`npm run check:components` ودمج التحقق في `npm run check`.
- تحديث فاحص الروابط ليستثني ملفات HTML المصدرية داخل `shared/components`؛ فهي قوالب وليست صفحات يزورها المستخدم مباشرة.

## قرار معماري مهم
لم أدمج كل الرؤوس والتذييلات في نسخة واحدة عامة؛ لأن محتواها وروابطها يختلف بين الصفحة الرئيسية والصفحات الداخلية، كما تختلف بعض روابط الأقسام النشطة. فرض نسخة واحدة الآن قد يغيّر التنقل أو يسبب تراجعاً بصرياً. لذلك اعتمدت مكونات مستقلة لكل صفحة كخطوة انتقالية آمنة، مع توليد HTML ثابت قبل النشر. هذا يتيح تعديل كل مكون من مصدر واحد واضح دون إضافة اعتماد وقت التشغيل.

## الاختبارات
- `npm run check`: ناجح.
  - 33 صفحة HTML: صفر مراجع محلية مفقودة.
  - كتالوج المشاريع: 12 سجلاً سليماً.
  - فحص تكامل عارض المشاريع: ناجح.
  - كتالوج المقالات: 14 بطاقة، 13 مقالاً مرتبطاً، ومدخل واحد غير متاح كما كان موثقاً سابقاً.
  - فحص المكونات: 12 مكوناً متطابقاً.
- `npm test`: 6 اختبارات لوظيفة Telegram ناجحة.
- فحص صياغة جميع ملفات JavaScript بواسطة `node --check`: ناجح.

## ما لم يتم اختباره
- لم يتم تشغيل اختبار بصري عبر متصفح حقيقي في هذه المرحلة.
- لم يتم النشر إلى Cloudflare Pages أو إجراء اختبار Preview حي.
- لم يتم تعديل التصميم أو النصوص أو سلوك روابط التنقل عمداً.

## طريقة الاستخدام
1. عدّل الملف المناسب داخل `shared/components/`.
2. شغّل `npm run build:components` لتحديث HTML الثابت.
3. شغّل `npm run check` للتحقق من سلامة المكونات والروابط والكتالوجات.
4. ارفع التغييرات إلى فرع التطوير ثم افحص Cloudflare Pages Preview قبل الدمج إلى `main`.
