# تقرير المرحلة السادسة — توحيد كتالوج المقالات

## ما تم
- إنشاء `data/blog-posts.json` بوصفه المصدر المركزي لبيانات بطاقات المدونة.
- نقل بيانات 14 بطاقة كانت مكتوبة يدوياً داخل `blog.html` إلى الكتالوج: العنوان، الوصف، التصنيف، الرمز، الشارة، التاريخ، زمن القراءة، خلفية البطاقة، وحالة توفر رابط المقال.
- تحويل شبكة المقالات إلى واجهة تُنشأ ديناميكياً من الكتالوج مع ترميز آمن للنصوص قبل إدراجها في HTML.
- الإبقاء على أزرار التصنيف والفلترة الجانبية وعدّاد النتائج ورسالة عدم وجود نتائج.
- إضافة أداة `scripts/validate-blog-catalog.mjs` وربطها بأمر `npm run check`.
- الإبقاء على صفحات المقالات الـ13 كما هي دون إعادة كتابة محتواها أو تغيير تصميمها.

## ملاحظات البيانات
- الكتالوج يحتوي 14 بطاقة كما كانت في الصفحة.
- 13 بطاقة ترتبط بصفحات مقالات موجودة.
- بطاقة أتمتة خدمة العملاء كانت تشير إلى `#` ولا توجد لها صفحة `blogs/14.html` في نسخة المشروع؛ لذلك تبقى ظاهرة لكن رابطها معطّل بوضوح، ولم يتم اختلاق صفحة أو محتوى.
- لا تزال أرقام الإحصاءات النصية في مقدمة الصفحة بحاجة إلى تحديث تحريري لاحق إن تغير عدد المقالات أو التصنيفات.

## الاختبارات
- فحص JSON: ناجح.
- فحص معرّفات المقالات وتفرّدها والحقول الإلزامية: ناجح.
- فحص وجود ملفات المقالات المرتبطة: ناجح.
- فحص صياغة JavaScript المضمن: يُجرى ضمن التحقق المحلي قبل التسليم.
- لم يُجر اختبار متصفح فعلي أو نشر Cloudflare في هذه المرحلة.

## طريقة إضافة مقال جديد
1. أنشئ صفحة المقال داخل `blogs/` باستخدام قالب المقالات المعتمد.
2. أضف سجلاً جديداً إلى `data/blog-posts.json` مع `id` فريد و`href` صحيح و`available: true`.
3. نفّذ `npm run check:blog` قبل الالتزام بالتغييرات.

## حدود التنفيذ
لم يتم تحويل صفحات المقالات التفصيلية إلى قالب موحد بعد؛ هذه المرحلة توحّد كتالوج بطاقات المدونة فقط، حفاظاً على محتوى وتنسيق الصفحات القائمة.
