# دليل الأداء وتجربة الاستخدام

- استخدم WebP للصور الجديدة متى كان ذلك مناسباً، واحتفظ بنسخة أصلية قابلة للتحرير.
- لا تستخدم `loading="lazy"` لصورة LCP أو الصورة الرئيسية الظاهرة فور فتح الصفحة.
- استخدم `loading="lazy"` للصور الواقعة أسفل الجزء المرئي، مع `decoding="async"`.
- لا تضف `fetchpriority="high"` إلا لصورة LCP المؤكدة بعد القياس.
- احترم إعداد `prefers-reduced-motion` ولا تجعل ظهور المحتوى متوقفاً على الحركة.
- حافظ على مؤشر تركيز مرئي للتنقل بلوحة المفاتيح.
- شغّل `npm run check` بعد أي تعديل؛ فهو يتضمن تدقيق الأداء الأساسي.
- لا تعتبر التدقيق الثابت بديلاً عن Lighthouse أو اختبار المتصفح الفعلي.
