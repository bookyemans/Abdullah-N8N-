# تقرير المرحلة الخامسة — كتالوج بيانات المشاريع

## الهدف
بدء نقل بيانات المشاريع من التكرار اليدوي داخل صفحات HTML إلى سجل مركزي منظم، مع المحافظة على شكل الموقع الحالي وسلوكه أثناء الانتقال.

## ما أُنجز
- إنشاء `data/projects.json` ويضم 12 سجلاً مستخرجاً من بطاقات المشاريع المنشورة في `projects.html`.
- توحيد حقول كل سجل: المعرّف، العنوان، التصنيف، الوصف، الوسوم، الصورة والنص البديل، صفحة التفاصيل، ملف سير العمل إن كان متاحاً، مراحل التكامل، مؤشرات النتائج، اللون، وحالة النشر.
- إنشاء `schemas/project.schema.json` لتوثيق شكل سجل المشروع والحقول المقبولة.
- إنشاء `scripts/validate-project-catalog.mjs` للتحقق من تفرّد المعرّفات، الحقول الأساسية، حالة النشر، وسلامة وجود المسارات المحلية المشار إليها.
- إضافة `npm run check:projects` ودمج فحص الكتالوج ضمن `npm run check`.
- إبقاء HTML الحالي كما هو في هذه المرحلة لتجنب إعادة بناء بطاقات العرض أو كسر البحث والفلاتر والنوافذ المنبثقة قبل اختبار سلوكها. لذلك فالكتالوج مركزي وجاهز، لكن واجهة العرض لم تتحول بعد إلى توليد ديناميكي منه.

## ملاحظات بيانات
- تم العثور على 12 بطاقة مشروع ذات معرّفات `project-01` إلى `project-12` في صفحة القائمة.
- توجد صفحات تفاصيل إضافية داخل `Manager/` لا تقابلها حالياً بطاقة منشورة في القائمة؛ لم أضفها تلقائياً إلى الكتالوج حتى لا أقرر نيابة عنك أنها مشاريع منشورة.
- حقول تنزيل ملفات سير العمل بقيت `null` عندما كان رابط التنزيل غير متاح (`#`). لم يتم اختراع روابط أو ملفات بديلة.
- بيانات الكتالوج منقولة من النصوص الظاهرة في بطاقات HTML، ولا تمثل تدقيقاً مستقلاً لصحة أرقام النتائج أو الادعاءات التسويقية.

## الاختبارات
- `node scripts/validate-project-catalog.mjs`: ناجح — 12 سجلاً فريداً وجميع الأصول المحلية المشار إليها موجودة.
- فحص صياغة ملفات JavaScript وسلامة JSON يجب تشغيله عبر `npm run check` في بيئة Node 18 أو أحدث.
- لم يتم تغيير `projects.html` بصرياً، ولم يتم نشر الموقع أو اختبار Cloudflare Preview في هذه المرحلة.

## الخطوة التالية
المرحلة 5-B: تحويل بطاقات `projects.html` تدريجياً إلى واجهة تُبنى من `data/projects.json`، مع الحفاظ على نفس الفئات والتصميم والبحث والفلاتر ونافذة التفاصيل، ثم مقارنة لقطات الشاشة واختبارات التفاعل قبل إزالة HTML القديم.
