# المرحلة 5-B — ربط واجهة المشاريع بالكتالوج المركزي

## ما تم
- أصبحت `projects.html` تقرأ المشاريع المنشورة من `data/projects.json` عبر `fetch`.
- توليد بطاقات المشاريع ديناميكياً مع المحافظة على فئات CSS الحالية، وعناصر الفلترة والبحث، وزر النظرة السريعة وصفحة التفاصيل.
- تغذية نافذة التفاصيل من بيانات الكتالوج بدلاً من الاعتماد على قائمة بيانات منفصلة مكررة.
- إظهار حالة تحميل ورسالة واضحة عند فشل تحميل ملف البيانات.
- إظهار زر تنزيل ملف التدفق فقط عندما يشير الكتالوج إلى توفر الملف.
- إضافة اختبار تكامل ساكن وربطه بأمر `npm run check`.

## ملاحظات
- يجب فتح الموقع عبر خادم HTTP/Cloudflare Pages؛ فتح `projects.html` مباشرة عبر `file://` يمنع المتصفح عادةً من جلب JSON.
- اختبارات هذه المرحلة ساكنة ولا تثبت سلوك المتصفح الفعلي أو نجاح نشر Cloudflare.
- لم يتم تعديل صفحات تفاصيل المشاريع أو إنشاء ملفات workflow غير موجودة.

## التحقق
شغّل `npm run check` من جذر المشروع.
