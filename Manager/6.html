من Epic Done إلى تقرير Lessons Learned

5 خطوات تلقائية تحدث فوراً عند اكتمال أي Epic.

1

Jira Trigger — Epic تتحول لـ "Done"

Webhook يراقب Jira باستمرار. عندما يتغير حالة Epic إلى "Done"، يتم تفعيل الأتمتة تلقائياً — مع فلتر ذكي يتجاهل التغييرات الأخرى.

Jira TriggerIf → Done
2

سحب جميع المهام والتعليقات

يتصل بـ Jira API ويسحب كل Issue تحت الـ Epic، ثم يسحب جميع التعليقات لكل مهمة — الوصف، العنوان، الحالة، اسم الـ Epic، وكل نقاش حدث.

Get IssuesGet CommentsEdit Fields
3

تجميع وتلخيص البيانات

Summarize Node يدمج كل التعليقات لكل مهمة في نص واحد مُنظم، مع ربطها باسم Epic والعنوان والوصف — جاهزة للتحليل الذكي.

SummarizeConcatenate
4

AI Agent يكتب تقرير Lessons Learned

GPT-4o-mini يُحلل كل البيانات ويكتب تقريراً منظماً يشمل: النتائج الرئيسية، الملاحظات، التوصيات العملية، المقاييس، والتصنيفات — بتنسيق Markdown احترافي.

AI AgentGPT-4o-miniBuffer Memory

إعداد سريع

1

استورد الملف في N8N

Import from File → اختر jira-retrospective.json

2

اربط Jira Cloud API

Credentials → Jira Software Cloud → أدخل البريد + API Token من Atlassian

3

اربط OpenAI + Google Docs

OpenAI API Key + Google Docs OAuth2. في Google Docs Node، حدد رابط المستند الهدف.

4

فعّل الـ Workflow!

فعّل "Active" — أي Epic تتحول لـ Done ستُولّد تقرير تلقائياً!
